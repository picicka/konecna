## Tagy na domech

Stav: seznam se průběžně doplňuje, tagy na domy budeme dávat. Mechanismus je hotový (`npm run osm` je přiřadí, `house()` je nastříká), přegenerovat se to má až po domluvě.

Graffiti nastříkané na parter domů. Převodník mapy (`npm run osm`) si tenhle seznam načte a tagy rozhází náhodně, ale
pokaždé stejně, po domech s fasádou do ulice. Jeden řádek = jeden tag, píše se velkými písmeny sprejem, diakritika
se dokreslí. Doplňovat sem.
