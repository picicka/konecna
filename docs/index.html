Rychlé skoky do hry

Odkaz spustí hru rovnou na místě, bez titulku, úvodu a tvorby postavy. Stav hry (vlajky, předměty, úkoly, důvěra) je takový, jaký má průchod npm test při příchodu na místo, takže postavy mluví jako při hraní. Zapisuje ho průchod do src/skoky.json; po změně příběhu stačí npm test a npm run build.
